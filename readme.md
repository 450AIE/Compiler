该项目是本人学习编译原理的一个项目，纯手搓，语法完全使用JS的语法


## 当前已实现
### 词法分析
支持变量，关键词，字符串，数字类型（暂不支持带前缀的数字解析，比如-5），操作符，括号等

### 语法分析
支持if，赋值语句，表达式，变量声明(数组，对象，函数，常量)，函数调用，for，while

## 预览
可以在frontend目录下运行npm run dev实时预览效果
